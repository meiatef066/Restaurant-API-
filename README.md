#  Spring Boot Java Project 

## Overview

This project is a **Spring Boot backend application** developed using Java. It is part of a client-server demo, showcasing backend functionality such as RESTful API handling, data persistence, and basic server-side logic.

##  Technologies Used

- Java 17+
- Spring Boot
- Spring Web
- Spring Data JPA 
- MySQL 
- Maven / Gradle
- Git

##  Features

- REST API endpoints
- CRUD operations
- Exception handling
- Layered architecture (Controller, Service, Repository)
- Integration with a frontend (client-server structure)
